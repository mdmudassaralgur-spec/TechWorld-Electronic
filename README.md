💻 TechWorld - Electronics & Gadgets Website

Welcome to TechWorld, a modern and fully responsive Electronics & Gadgets Store web application built using HTML5, CSS3, JavaScript, and Streamlit Python.

🚀 Features & Functionality

Interactive Product Catalog: Advanced search and category/brand filters for Smartphones, Laptops, Audio devices, and Wearables.

Shopping Cart System: Real-time quantity updates, subtotal calculation, and the TECH100 promo code discount ($100 off).

Wishlist Management: Save favorite products to your wishlist and move them to the cart with a single click.

Secure Checkout Simulation: Place orders with detailed shipping information and multiple payment methods (Credit Card, UPI, Cash on Delivery).

User Account & Order History: Login/Register authentication system and past order tracking.

Responsive UI/UX: Clean, modern design featuring dark blue (#0A2647) and tech blue (#00B4D8) themes optimized for both mobile and desktop.

🛠️ Technology Stack

Frontend / UI: HTML5, CSS3, JavaScript / Streamlit Python

State Management: Session State (st.session_state)

Icons & Styling: Custom CSS, Emojis, Responsive Grid Layout

📦 Installation & Setup Guide

To run this application locally using Python and Streamlit, follow these steps:

Step 1: Install Python

Verify that Python is installed on your computer by running this command in your terminal or command prompt:

python --version


Step 2: Install the Streamlit Library

Install Streamlit by executing the following command in your command prompt:

pip install streamlit


Step 3: Set Up Project Files

Create a new folder on your computer.

Inside that folder, create a file named app.py, paste the Streamlit Python code into it, and save the file.

Step 4: Run the Website

Navigate to your project folder path in the command prompt and run the following command to start the web application:

streamlit run app.py


Step 5: View the Live Website

Once the command executes, your default web browser will automatically open (or you can navigate tocc  http://localhost:8501), displaying your live TechWorld store!
